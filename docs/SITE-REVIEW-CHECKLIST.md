# Site Review Checklist

Use this checklist before pushing visible portfolio changes to <https://rollycalma.com/>.

## First viewport

- The name "Rolly Calma" is immediately visible.
- The role is clear: Python developer and AI automation builder.
- Main proof numbers match the GitHub profile README badges.
- Calls to action lead to projects, services/proof demos, and GitHub.

## Trust signals

- Public claims link to source code, case studies, or live demos.
- Employer-facing content avoids noisy or unrelated topics.
- AI assistance is described as a workflow aid, not as a contributor credit.
- Contact and start pages stay easy to reach from the nav.

## Quick checks

- Open the home page on desktop and mobile widths.
- Confirm the visual proof engine does not leave the hero feeling unbalanced.
- Check that `llms.txt` and structured data match the live positioning.
- Run a local static server before publishing larger HTML/CSS edits.
